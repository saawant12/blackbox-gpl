- **The `blackbox.elf` release files.** Archive.org's size limit cut the downloads short, so its copies are incomplete. The SHA-256 of every file examined is in [`SHA256SUMS`](SHA256SUMS), and [`check.sh`](check.sh) checks the files on GitHub against it.
- **The x.com post pages.** x.com blocks archive.org, so X's own embed data for both posts is archived above instead.
